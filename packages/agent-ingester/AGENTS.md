# agent-ingester

Central telemetry ingestion daemon (`agent-ingester`) that receives agent events, computes token pricing, manages SQLite storage, and broadcasts updates.

## Commands
- Dev: `just run`
- Build: `just build`
- Test: `just test` (enforces >= 90% statement coverage gate via `scripts/check-coverage.sh`)
- Check coverage: `just check-coverage` (repo root task checking all Go packages)
- Lint: `just lint`

## Local conventions
- Store DSNs carry only per-connection pragmas (WAL, `synchronous`, `busy_timeout`, `foreign_keys`). File-level settings such as `auto_vacuum` are applied by `Migrate` at startup, never in the DSN, because setting them needs a write lock and would block every new connection behind an open write transaction. `Migrate` converts any database whose `auto_vacuum` is not incremental with one `VACUUM`, which needs free disk space about the size of the database. Each `:memory:` store is a private database on its single connection; never use `cache=shared`, which makes an in-memory database visible process-wide under modernc.
- SQLite schema migrations are defined sequentially in `internal/store/migrations.go`. Table rebuild migrations must pin a single dedicated connection via `db.Conn(ctx)` to disable foreign keys, run the transaction, verify `PRAGMA foreign_key_check`, and re-enable foreign keys, preventing accidental cascade deletion of related tables across pooled connections.
- Structured rate-limit metadata (`RateLimitResetAt`, `RetryAfterSeconds`) extracted from telemetry frames is persisted to the `agents` table and attached to `IAgentActivity`, elevating activity to `RATE_LIMITED`; rate-limit reset fields are cleared whenever the resulting activity is not `RATE_LIMITED` (`internal/classifier/root_state.go`, `internal/classifier/subagents.go`, `internal/store/store.go`).
- Silence timers are scheduled on rate-limit error frames (`scheduleSilenceTimerLocked`) so that unrecovered or abandoned throttled sessions transition to `IDLE` after the silence timeout window instead of stalling in `RATE_LIMITED` indefinitely (`internal/classifier/root_state.go`, `internal/classifier/timers.go`).
- Hidden agent state is stored in SQLite (`is_hidden`, `hidden_at`); incoming telemetry frames with new activity automatically reset `is_hidden = 0`.
- Real-time updates broadcast over Unix domain socket `$XDG_RUNTIME_DIR/agent-status/notify.sock` via `internal/notify/publisher.go`.
- Turn-end debouncing uses `DefaultIdleGracePeriod = 5s` (configurable via `--idle-grace-period` CLI flag or `AGENT_STATUS_IDLE_GRACE_PERIOD` environment variable) to smooth short gaps between tool results and subsequent thinking turns before declaring idle; replay disables the idle grace period (`SetIdleGracePeriod(0)`) to evaluate event sequences without simulated wall-clock debounce delays.
- Turn completion retention sets `HasUnseenCompletion = true` and `CompletedAt` timestamp when a turn ends without error or pending question, retaining completion state until a new user turn or explicit dismissal.
- Turn completion dismissal write path: `agent-ingester` exposes `PATCH /api/v1/internal/agents/{id}` (supporting unified patch payloads with `dismissCompletion` alongside `isHidden`). Dismissal and frames share context initialization so they use the same cached completion and writer lock, including after an ingester restart. Under that lock, `DismissAgentCompletion` resets `has_unseen_completion = 0` and clears `completed_at = NULL` in SQLite before the classifier clears the observed cached completion and broadcasts `agent_upsert`. Failed writes preserve cached completion; a newer completion prepared during the write is retained. Frames reconcile carried-over completion with the cache before publishing their state, then refresh it under the writer lock before saving. These two checks prevent a frame from restoring dismissed completion in either the cache or SQLite while preserving completion newly generated by the frame. Both asynchronous and synchronous trailing summaries read and save under the same writer lock and reconcile completion with the cache before saving.
- Internal HTTP API authentication is applied by `Receiver.InternalHandler` before routing agent patches and focus requests. Store mutations return `store.ErrAgentNotFound` for absent agents; handlers map that sentinel to 404 and storage failures to 500.
- Activity classification precedence elevates `RATE_LIMITED` above standard idle/busy states: a root or subagent rate limit takes precedence over idle status, rolling up subagent rate-limit errors (e.g. `[Subagent <id>] rate limit exceeded`).
- WebSocket receiver configures a 64 MiB read limit (`conn.SetReadLimit(64 * 1024 * 1024)`) on observer connections to handle oversized frame batches, diffs, and bash outputs.
- Telemetry and session logging resolves human environment and project names for clean human-facing logs while preserving machine IDs under `AGENT=1`.
- Pricing calculations use static rates defined in `internal/pricing/pricing.go`.
- Action summarization runs asynchronously via per-agent serialized queues to avoid blocking WebSocket ingestion; when an agent is in `ActivityRateLimited`, external LLM summarization is bypassed to preserve the deterministic action (`"Rate limit reached — backoff/retry in progress"`) and `phase = nil`.
- Summaries use specialized prompt templates (Thinking + Tool, Thinking only, Tool only) with sanitized tool arguments (max 300 chars).
- Semantic deduplication rejects state updates with >= 60% word overlap (Jaccard similarity) when target and phase are unchanged.
- Herdr terminal window activation (`activateTerminalWindow`) uses thread-safe `herdr.MockExecCommand` for test mocking to prevent OS window focus-stealing on macOS.

## Local gotchas
- Unlisted models report `nil` cost rather than `$0.00` to distinguish free usage from unknown rates.
- Retention cleanup runs every hour to prune events older than 48 hours and exited agents older than 30 days (`internal/store/prune.go`).
- Subagent frames must not cancel the root idle timer; idle-timer validity is keyed by `agentContext.rootGeneration`, not `UpdatedAt` (`internal/classifier/timers.go`).
- `current_run_id` in SQLite is non-NULL only for unended runs, and an exited agent reloads with `CurrentRun == nil` (`internal/store/store.go`, `internal/classifier/root_state.go`).
- Root activity context (`actx.rootActivity`) is strictly isolated from subagent composite/rolled-up activity so a busy subagent cannot pin the root to BUSY after subagent completion (`internal/classifier/subagents.go`).
- Minimum visibility dwell smoothing preserves completed short-lived subagents in `ActiveSubagents` for a configurable dwell threshold (`DefaultSubagentDwell = 30s`, `SetSubagentDwell`), tracking `StartedAt`, `CompletedAt`, and `Status` ("running" vs "completed") before eviction (`internal/classifier/subagents.go`).
- Active state floors preserve BUSY during long tool runs and model inference: Thinking Floor (TurnFloor) latches BUSY across inference latency windows, In-Flight Floor (FlightFloor) latches BUSY while a registered tool awaits `tool_result`, and silence timers distinguish open in-flight tools from finished turns with a 30-minute turn silence timeout (`internal/classifier/root_state.go`, `internal/classifier/timers.go`).
- Failed subagent `tool_result` frames (`IsError = true`) keep the subagent in `BUSY` status (matching root agent behavior) rather than escalating to `ERROR` or `RATE_LIMITED`; only genuine subagent `error` frames escalate activity, and error outputs are truncated strictly on UTF-8 rune boundaries (`internal/classifier/subagents.go`).
- Per-agent persistence: `ProcessFrame` holds a per-agent frame lock (`lockFrames`) from reading the agent row to saving it, so frames for one agent from overlapping observer connections cannot overwrite each other's usage or state. Writers outside `ProcessFrame` (summary jobs, synchronous trailing summaries, idle and silence transitions, subagent dwell expiry) save only through `persistAgent`, which re-reads the row under the context's `persistMu` and runs the writer's mutation under `c.mu` only while that context is still current. Each mutation re-checks `saveGeneration` (incremented on every frame) and, for root transitions, `rootGeneration`, and returns false to skip a stale write. From the moment a frame increments `saveGeneration` until it saves, `frameInFlight` is set, because the frame has already copied the cache into the row it is about to save. While it is set, idle transitions and subagent dwell expiry retry after 100ms (dwell expiry also retries after any newer frame, since a frame with a lagging clock does not prune), summaries wait and retry only their save (`persistAgentAfterFrame`), and silence transitions skip. Every writer that rolls up activity caches the completion it saves (`captureCompletionLocked`), so the next frame cannot undo it. A failed save is logged and never broadcast. Lock order is frame lock, then `persistMu`, then `c.mu`; dismissal and background writers never take the frame lock (`internal/classifier/persistence.go`).
- Agent contexts are cached only after the agent's full subagent history loads (`GetDistinctSubagentIDs`). If it cannot be read, `ProcessFrame` and dismissal return an error and the next call retries, so a returning subagent is never counted twice (`internal/classifier/context.go`).
- Turn-end grace period: `turn_end` events schedule `handleIdleTransition` via `DefaultIdleGracePeriod = 5s` (configurable via `--idle-grace-period` / `AGENT_STATUS_IDLE_GRACE_PERIOD`). This debounces the transition to IDLE across multi-turn agent execution while attention states (`WAITING_QUESTION`, `ERROR`) bypass the grace period immediately. Out-of-scope conversational events (`text`, `agent_message`) do not alter classifier activity states.
- Subagent dwell timer synchronization and testing: `afterSubagentDwellHook` provides deterministic synchronization in tests when subagent dwell timers fire and persist updated state; in `handleSubagentDwellExpired`, timer expirations arriving slightly earlier than `startedAt + dwellMs` due to clock jitter (<= 1ms difference) proceed with eviction, while larger differences reschedule the timer rather than dropping it silently, and async test frames anchor timestamps (`fSubEnd.Timestamp = fSubStart.Timestamp + 1`) to prevent scheduling pauses between test statements from exceeding dwell thresholds before turn completion frames are processed (`internal/classifier/subagents.go`, `internal/classifier/classifier_test.go`).

## Boundaries
- Always (code-based projects only): any time code is changed such that results from running that code are changed, a test file must be changed as well; 90% statement coverage is required and enforced on `just test` via `scripts/check-coverage.sh` (scripts/ folder is excluded from this rule)
- Always: automatically record all new user instructions in the most appropriate `AGENTS.md` file immediately upon receipt (check with user if existing instructions conflict)
- Ask first: adding database schema migrations or changing activity classification logic
- Never: block WebSocket ingestion handlers on synchronous LLM summarizer calls
- Never: publish releases automatically without explicit user authorization
